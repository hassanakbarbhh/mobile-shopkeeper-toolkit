# Play Console Checklist

1. **Developer Account:** Log into Google Play Console and pay the registration fee if not done already.
2. **Create App:** Click "Create App", enter "Mobile Shopkeeper Toolkit".
3. **Upload AAB:** Download the `.aab` file from GitHub Actions artifacts for tag `v6.0.0` and upload it under App Bundle.
4. **Content Rating:** Business app, no restricted content -> Everyone.
5. **Data Safety:** Fill out the Data Safety form as per `store/data-safety.md`.
6. **Pricing & Distribution:** Set pricing to Free. Select countries you wish to distribute to.
7. **Release Tracks:** Publish to the Internal Test track first to verify installation on physical devices.
8. **Staged Rollout:** Promote to Production using a staged rollout (e.g. 10% -> 50% -> 100%).
